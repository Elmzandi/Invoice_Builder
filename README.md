# Invoice Builder

Invoice Builder is a web application that helps businesses create, manage, and download professional invoices from business data.

## Features

- Customer Management
- Sender Management
- Invoice Management
- PDF Generation
- Modern React UI

## Tech Stack

Backend

- ASP.NET Core 10
- Minimal APIs
- Entity Framework Core
- PostgreSQL

Frontend

- React
- TypeScript
- TailwindCSS

Infrastructure

- Docker Compose
- GitHub Actions
